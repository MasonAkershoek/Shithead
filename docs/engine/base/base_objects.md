# base_objects.lua
---
## Definition:
base_objects.lua holds all the base objects needed to contruct the rest of the game objects

| Object | Description |
| ----------- | ----------- |
| [Node](engine/base/node.md) | Base for all game objects |
| [Moveable](engine/base/moveable.md) | Base for all movable objects in the game |
| [Sprite](engine/base/sprite.md) | Base object for all game objects that display a texture |
| [Vector](engine/base/vector.md) | Vector2D object |
